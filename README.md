# Upscalforge Games

مشروع ألعاب Roblox. هذا الفرع (`claude/new-game`) فيه **Brick Farm**: مزرعة اجتماعية بأسلوب ليغو (مثل Happy Farm). الفكرة والتقدم في [docs/brick-farm.md](docs/brick-farm.md). الكود في `brickfarm/`، يتبنى بـ Rojo (`brickfarm.project.json`).

- `tests/loader.luau`: أداة تحمّل كود Luau خارج Roblox باش نختبرو القواعد بـ Lune.
- الألعاب القديمة (Cubeling Nest، Gem Dig، Glowspire، Cubedash) محفوظة في تاريخ git، ونقدر نرجعوها كي تحب.
