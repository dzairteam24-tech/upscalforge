# Upscalforge Games

ألعاب هاتف بـ **Godot 4** موجهة للسوق الأجنبي.

## الخطة المتفق عليها

- **المحرك:** Godot 4
- **المنصة:** Android (Google Play)
- **السوق:** أجنبي، واللعبة والمتجر بالإنجليزية
- **كل لعبة تطبيق مستقل** في المتجر
- **الربح:** إعلانات (AdMob) ومشتريات داخل اللعبة
- **النوع المقترح:** hybrid-casual

## الهيكل المقترح

```
games/<game>/   مشروع Godot مستقل لكل لعبة
shared/         كود مشترك: الإعلانات، المشتريات، الحفظ، الإعدادات
```

## المرحلة الحالية

نحددو أفكار الألعاب قبل ما نبداو البرمجة.
