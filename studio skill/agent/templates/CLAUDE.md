## Standing rules

- Never redo approved work.
- Never propose an idea that is in `ideas-log.md`.
- File headers are the truth; rebuild the video table and `NEXT-STEPS.md` from them.
- One production stage per session; invoke that stage's Skill first.
- Never edit `.claude/skills/` or the master library.
- Never delete; move to `_trash/<date>/` with a `MANIFEST.md`.
- Speak to the user in the user's chat language; write files in English.
