# QUICKSTART / البدء السريع

## العربية

**ثلاث خطوات:**
1. افتح الطرفية (Terminal) داخل مجلد المشروع.
2. اكتب: `claude --agent story-studio` (في مشروع تم إعداده من قبل يكفي: `claude`).
3. قل الجملة المناسبة من الجدول.

| ماذا تريد | الجملة |
|---|---|
| إعداد مشروع جديد | «جهّز هذا المجلد كمشروع جديد» |
| بدء فيديو جديد | «ابدأ فيديو جديداً: ابحث لي عن أفكار» |
| المتابعة بعد إعادة التشغيل | «أين وصلنا؟ أكمل الخطوة التالية» |
| بعد إنتاج الصور أو المقاطع | «وضعت الملفات في المجلد» |
| تنظيف المشروع | «نظّف المشروع» |
| إفراغ سلة المحذوفات | «أرني محتوى `_trash` ثم أفرغها» |

**ما الذي تراجعه في كل مرحلة:**
1. الأفكار: هل الفكرة قصة فعلاً، وهل مصادرها مفتوحة ومذكورة؟
2. السيناريو: هل يتغير شيء في كل مشهد، وهل الحوار لا يشرح المشاعر؟
3. الدليل البصري: هل الأوصاف ثابتة، وهل الصور المرجعية تشبه ما تريد؟
4. اللقطات: الملخص من صفحة واحدة، غرض كل مشهد، وثلاث لقطات نموذجية.
5. التجهيز: هل العنوان والصورة المصغرة يعدان بما في الفيديو فعلاً؟

كل مرحلة في جلسة جديدة: اخرج، شغّل `claude` من جديد، وقل الجملة.

**التثبيت على حاسوب جديد:** انسخ المستودع (clone)، ثم داخل مجلد `studio skill` اكتب: `sh install.sh`

## English

**Three steps:**
1. Open the terminal in the project folder.
2. Type: `claude --agent story-studio` (in a project already set up, `claude` is enough).
3. Say the sentence from the table.

| You want to | Say |
|---|---|
| Set up a new project | "Set up this folder as a new project" |
| Start a new video | "Start a new video: find me ideas" |
| Continue after a restart | "Where are we? Continue with the next step" |
| Report produced media | "I put the files in the folder" |
| Clean the project | "Clean the project" |
| Empty the trash | "Show me what is in `_trash`, then empty it" |

**What to review at each stage:**
1. Ideas: is it a story, and are its sources opened and listed?
2. Screenplay: does something change in every scene, and does the dialogue avoid explaining feelings?
3. Bible: are the descriptions fixed, and do the reference images match what you want?
4. Shots: the one-page summary, each scene's purpose, three sample shots.
5. Packaging: do the title and thumbnail promise what the video delivers?

One stage per session: exit, run `claude` again, say the sentence.

**Install on another computer:** clone the repository, then inside the `studio skill` folder run: `sh install.sh`
