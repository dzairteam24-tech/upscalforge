# Export Profiles — Adobe Stock (design)

Status: **design; not implemented.** Requested by the owner on 2026-09-29.

An *export profile* is a named, versioned set of output rules plus a
compliance check. The first profile is **Adobe Stock (photos)**. The rules
live in a versioned data file (`policy/export/adobe-stock-photo.json`, created
at implementation time) so they can be updated when Adobe changes its
requirements, without a code change.

## 1. Source of the rules and their reliability

Adobe's help pages could not be fetched directly from the development
environment (network egress blocked). The rules below were taken on
2026-09-29 from Adobe's official help pages **as returned by web search**.
They must be re-checked against the live pages before relying on them:

- [Adobe Stock photo submission requirements](https://helpx.adobe.com/stock/contributor/submit-your-content/submit-photos/technical-legal-requirements-photo-submission.html)
- [Requirements for contributing photos and illustrations](https://helpx.adobe.com/in/stock/contributor/help/photography-illustrations.html)
- [Adobe Stock generative AI content guidelines](https://helpx.adobe.com/stock/contributor/submit-your-content/submit-generative-ai-content/generative-ai-content-guidelines.html)
- [Adobe Stock quality and technical standards](https://helpx.adobe.com/stock/contributor/content-moderation/quality-technical-standards-reasons-content-refusal.html)

| Rule (as reported) | Profile behaviour |
|--------------------|-------------------|
| Format JPEG, **sRGB colour profile** | Encode baseline JPEG with our encoder. Convert to sRGB and embed an sRGB ICC profile generated by our own code from the published sRGB parameters. |
| Resolution **4 MP – 100 MP** | Validate. Choose the smallest scale that reaches ≥ 4 MP. If a native scale overshoots 100 MP, downscale the result with our resampler to ≤ 100 MP. |
| File size **≤ 45 MB** | Search for the highest JPEG quality (from a floor, e.g. 90) whose output is ≤ 45 MB. Fail with an explanation if the floor does not fit. |
| "Don't compress files too much" | Quality floor. Never go below it silently. |
| "Don't enlarge files" / don't increase resolution in a way that degrades quality | **Enlargement risk warning** whenever scale > 1, stating the factor. Faithful mode is the profile default, strict QC gates apply, and the report says plainly that enlarged images may be rejected. |
| No noise, dust or artefacts; no invasive post-processing | Denoise and compression cleanup driven by analysis. Sharpening is capped. QC checks for halos, oversharpening and consistency loss must pass, otherwise the export fails with the findings. |
| Generative AI: label with "Created using generative AI tools" when AI changed, augmented or added the primary subject, or significantly changed a human subject | The report contains an **AI disclosure section** listing every AI component used (engine path, model, provenance) and whether the synthesis path or face restoration ran. It recommends the label when synthesis (Balanced/Reconstruction) or face restoration was used. The final decision stays with the user. |
| Contributors must have the right to submit content made with the AI tools used | **Hard rule:** models tagged `licence_scope: non-commercial` (CodeFormer, GFPGAN) are **blocked** in this profile. External models tagged `commercial` are allowed, and the report notes the training-data caveat from the model register. The classical engine and ScaleForge-trained models have no restriction. |
| Model or property releases for identifiable people or property | Outside image processing. The report reminds the user. |

## 2. Pipeline placement

`JobRequest.export_profile = AdobeStockPhoto` constrains the strategy engine:
- allowed models and modes;
- scale choice;
- the colour conversion target (sRGB), which overrides native-encoding
  processing (ADR-0005) at the output stage only;
- the encoder settings.

The compliance check runs on the final encoded file (dimensions, megapixels,
bytes, embedded profile, JPEG parameters) and on the QC report. The result is
**Pass**, **Pass with warnings** (e.g. enlargement), or **Fail** with reasons.
A file is never labelled "compliant" if any check fails.

## 3. Consequences for earlier decisions

- **Usage scope clarified:** the software is used locally by the owner, but
  its outputs may be sold (Adobe Stock). Non-commercial models may therefore
  only be used for images that will not be sold. The Adobe Stock profile
  enforces this. ADR-0015 and the model register are updated.
- **Colour:** an sRGB conversion path (matrix and TRC profiles) is required
  in Phase 11, not just profile pass-through. Inputs whose profile cannot be
  converted exactly (e.g. LUT-based profiles) are refused by this profile
  with an explanation.

## 4. Limits of what the profile can promise

Adobe's review includes human judgement of quality and content. The profile
can only guarantee the **measurable technical rules** above. It cannot
guarantee acceptance, and the report says so.
